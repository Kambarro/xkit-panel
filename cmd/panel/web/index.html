Загрузить свой сайт

ZIP-архив со статическим сайтом (index.html обязателен). До 10 МБ. Только HTML/CSS/JS/картинки — без PHP/скриптов на сервере. Ваш сайт не сбрасывается при обновлении панели.

Перетащите ZIP сюда или нажмите для выбора файла

Требования

  • index.html в корне архива — обязателен
  • Статический сайт: HTML, CSS, JS, изображения, шрифты
  • Без серверных скриптов (PHP, Python, CGI) — nginx отдаёт статику
  • Размер до 10 МБ. Реалистичный сайт = лучшая маскировка
  • Пользовательский сайт сохраняется при обновлении/бэкапе панели
  • REALITY-протоколы показывают этот сайт при пробинге (правдоподобно)
