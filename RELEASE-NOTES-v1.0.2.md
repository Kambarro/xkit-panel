## v1.0.2 — 2026-11-28

Исправления процедуры входа и повторной установки.

### Установка поверх существующей базы
- `install.sh`: если админ уже есть в SQLite, установщик больше не печатает пароль из свежего `pass.conf` (он не попадал в БД — вход не работал). После старта выполняется `xkit-panel reset-password`, и показанный логин/пароль гарантированно совпадают с хешем в базе.

### Страница смены одноразового пароля
- Передаётся логин админа и добавляется скрытое поле `username` — менеджер паролей браузера больше не спрашивает «выберите логин для обновления».
- «Глазик» показа/скрытия пароля для обоих полей.
- Живая проверка совпадения двух паролей и очистка ошибки перед повторной отправкой.

### Страница входа
- «Глазик» показа/скрытия пароля при вводе.
